# egypt-locations.json

27 governorates and 396 cities, Arabic and English. Source: https://github.com/Tech-Labs/egypt-governorates-and-cities-db (MIT license, copyright the Tech-Labs authors). IDs are the dataset's own IDs.

Local fixes to the source: the governorate name الإسماعلية is spelled الإسماعيلية, and seven city English names that were lowercase transliterations were rewritten.
